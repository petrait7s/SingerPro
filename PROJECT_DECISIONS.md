# Project decisions

| #   | Decision                                                                                                                                                                                                                                  | Reason / implication                                                                                                                                 |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Product identity "Singer Pro"; developer PETRA Software Solutions; supplied logo = PETRA logo                                                                                                                                             | Owner-confirmed. PETRA mark used subtly (About, login from P1, invoice footer from P3). No Singer/Beko marks.                                        |
| D2  | Stack: Tauri 2, React 19, TS 5.9, Vite 7, Tailwind 4, Rust, SQLite via SQLx 0.8, pnpm 10                                                                                                                                                  | Stable, mutually compatible. Latest majors (Tauri 3 alpha, TS 7, Vite 8) deliberately not used.                                                      |
| D3  | Rust split: `crates/core` (no Tauri) + `src-tauri` (thin command layer)                                                                                                                                                                   | Core fully testable on Linux without WebKit; enables a future server reuse.                                                                          |
| D4  | Money = `i64` paisa, `Money` newtype with checked ops                                                                                                                                                                                     | No floats. Display uses lakh/crore grouping (৳1,25,000.50). Percent rounds half away from zero.                                                      |
| D5  | IDs = UUIDv7 stored as TEXT                                                                                                                                                                                                               | Time-ordered, portable to PostgreSQL `uuid`.                                                                                                         |
| D6  | Timestamps UTC RFC3339 TEXT; Dhaka (fixed UTC+6, no DST) for display and business-day boundaries                                                                                                                                          |                                                                                                                                                      |
| D7  | SQLite: WAL, `synchronous=FULL`, FK on every connection, busy_timeout 5s                                                                                                                                                                  | Durability over speed for financial data.                                                                                                            |
| D8  | `audit_logs` append-only via DB triggers; `actor_id` has no FK                                                                                                                                                                            | Audit must outlive users.                                                                                                                            |
| D9  | `branches` table with one default branch from P0                                                                                                                                                                                          | Multi-branch later is additive.                                                                                                                      |
| D10 | Document numbers via `document_sequences`, incremented in caller's transaction                                                                                                                                                            | Unique; rollback releases the number.                                                                                                                |
| D11 | Defaults seeded (never overwritten): tax disabled 0%, installment markup 0%, remainder to last installment, markup recognised proportionally to collections, no negative stock, returns need inspection                                   | All configurable settings; owner-approved where stated.                                                                                              |
| D12 | Tauri capabilities = `core:default` only; CSP self-only; no fs/shell/http plugins                                                                                                                                                         | Least privilege. Backup/restore (P1) will use narrow custom commands.                                                                                |
| D13 | Non-built modules show an honest "scheduled for Pn" page, not fake data                                                                                                                                                                   | No dead controls / mock KPIs.                                                                                                                        |
| D14 | Windows build runs on `windows-latest`; Linux job does lint/test                                                                                                                                                                          | Installer is unsigned until a certificate is supplied (SmartScreen warning expected).                                                                |
| D15 | First-run setup creates the Owner with a password chosen by the installer; there is no default credential. Setup runs in `BEGIN IMMEDIATE` and fails once any user exists                                                                 | Directive 1. Concurrency-tested (5 parallel attempts -> exactly 1 owner).                                                                            |
| D16 | Argon2id (19 MiB, t=2, p=1, 16-byte random salt), PHC string storage. Password policy: >= 10 chars, not common, not containing username, not single repeated char, not digits only                                                        | OWASP parameters. Admin-created and admin-reset accounts must change the password at first sign-in; until then every permission check fails closed.  |
| D17 | Lockout: 5 consecutive failures lock the account 15 min; login errors never say which part was wrong; unknown users pay the same hashing cost                                                                                             | Anti brute-force and anti-enumeration. All attempts audited.                                                                                         |
| D18 | Sessions: random 256-bit token, SHA-256 of it kept in memory only, 30 min idle / 12 h absolute. The token is held in Rust (`AppState`); the webview never sees it                                                                         | A compromised web view cannot steal a session. Single-PC app, so in-memory sessions are sufficient; restart = sign in again.                         |
| D19 | Permissions are reloaded from the DB on every request (no cached grants)                                                                                                                                                                  | Role changes and deactivation take effect immediately. Authorization is enforced in `singerpro-core` services; the UI only hides what it cannot use. |
| D20 | Privilege-escalation rules: only an Owner may grant/modify Owner; others may only grant permissions they hold; the Owner role is immutable; at least one active Owner must always remain; no self-deactivation                            | Prevents a `users.manage` holder from taking over the system.                                                                                        |
| D21 | Settings are a closed, typed catalogue (unknown keys rejected, atomic updates, before/after audit). Tax keys need `tax.manage`. Rates entered as percent, stored as basis points                                                          | Directive 6. Tax/markup defaults remain 0 / disabled.                                                                                                |
| D22 | Logo stored in `binary_assets` (included in backups); only PNG/JPEG accepted, type sniffed from bytes, max 512 KB                                                                                                                         | No filesystem permission needed; SVG rejected (script risk).                                                                                         |
| D23 | Backup = SQLite `VACUUM INTO` (consistent while running) to a `.partial` file, verified (integrity + FK + schema) then renamed, with a SHA-256 `.manifest.json` sidecar. Existing files are never overwritten                             | `.spbak` extension.                                                                                                                                  |
| D24 | Restore is STAGED while running (verify, safety copy of live DB, byte-checked staged copy) and APPLIED at next startup before the DB is opened. The replaced DB is kept in `replaced/<timestamp>/`; a failed apply puts the original back | Avoids Windows file locks and half-overwritten databases. Nothing is deleted automatically.                                                          |
| D25 | Backups from a newer schema than the app are refused; older ones are accepted and migrated on open                                                                                                                                        | Forward-compatibility safety.                                                                                                                        |
| D26 | Language toggle EN/বাংলা (stored locally and as `ui.language`); Bangla body = Hind Siliguri, formal headings = Tiro Bangla, ৳ falls back to Hind Siliguri inside the Montserrat stack                                                     | Verified by `scripts/font-check.mjs`.                                                                                                                |
| D27 | `tauri-plugin-dialog` with `dialog:allow-open` only, used for choosing backup folder/file. No fs plugin                                                                                                                                   | Least privilege.                                                                                                                                     |
