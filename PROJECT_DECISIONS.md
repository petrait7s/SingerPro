# Project decisions

| #   | Decision                                                                                                                                                                                                | Reason / implication                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| D1  | Product identity "Singer Pro"; developer PETRA Software Solutions; supplied logo = PETRA logo                                                                                                           | Owner-confirmed. PETRA mark used subtly (About, login from P1, invoice footer from P3). No Singer/Beko marks. |
| D2  | Stack: Tauri 2, React 19, TS 5.9, Vite 7, Tailwind 4, Rust, SQLite via SQLx 0.8, pnpm 10                                                                                                                | Stable, mutually compatible. Latest majors (Tauri 3 alpha, TS 7, Vite 8) deliberately not used.               |
| D3  | Rust split: `crates/core` (no Tauri) + `src-tauri` (thin command layer)                                                                                                                                 | Core fully testable on Linux without WebKit; enables a future server reuse.                                   |
| D4  | Money = `i64` paisa, `Money` newtype with checked ops                                                                                                                                                   | No floats. Display uses lakh/crore grouping (৳1,25,000.50). Percent rounds half away from zero.               |
| D5  | IDs = UUIDv7 stored as TEXT                                                                                                                                                                             | Time-ordered, portable to PostgreSQL `uuid`.                                                                  |
| D6  | Timestamps UTC RFC3339 TEXT; Dhaka (fixed UTC+6, no DST) for display and business-day boundaries                                                                                                        |                                                                                                               |
| D7  | SQLite: WAL, `synchronous=FULL`, FK on every connection, busy_timeout 5s                                                                                                                                | Durability over speed for financial data.                                                                     |
| D8  | `audit_logs` append-only via DB triggers; `actor_id` has no FK                                                                                                                                          | Audit must outlive users.                                                                                     |
| D9  | `branches` table with one default branch from P0                                                                                                                                                        | Multi-branch later is additive.                                                                               |
| D10 | Document numbers via `document_sequences`, incremented in caller's transaction                                                                                                                          | Unique; rollback releases the number.                                                                         |
| D11 | Defaults seeded (never overwritten): tax disabled 0%, installment markup 0%, remainder to last installment, markup recognised proportionally to collections, no negative stock, returns need inspection | All configurable settings; owner-approved where stated.                                                       |
| D12 | Tauri capabilities = `core:default` only; CSP self-only; no fs/shell/http plugins                                                                                                                       | Least privilege. Backup/restore (P1) will use narrow custom commands.                                         |
| D13 | Non-built modules show an honest "scheduled for Pn" page, not fake data                                                                                                                                 | No dead controls / mock KPIs.                                                                                 |
| D14 | Windows build runs on `windows-latest`; Linux job does lint/test                                                                                                                                        | Installer is unsigned until a certificate is supplied (SmartScreen warning expected).                         |
